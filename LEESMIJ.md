# Prompt

**Prompt** is een gratis, open-source programma voor **Windows, macOS en Linux** dat naast Claude staat. Het toont alle slash-commands en skills die Claude Code kent, met één klik te kopiëren, laat je kiezen welke skills Claude laadt, en heeft een marktplaats met 55 kant-en-klare skills.

*English: [README.md](README.md).*

## Wat het doet

- **Mijn commands:** al je skills, commands, projectskills, plugins en de ingebouwde commands van Claude Code, met uitleg en een voorbeeld. Klik op **Kopieer** en het staat op je klembord.
- **Skills kiezen voordat je Claude start:** elke skill heeft een schakelaar. Uit = Prompt zet hem in `~/.claude/skills-uit`, zodat Claude hem niet laadt. Bewaar je keuze als **set** en zet hem later met één klik weer aan. **Start Claude** opent Claude met jouw keuze.
- **Marktplaats:** 55 skills in 12 categorieën. Installeren, bijwerken, aan/uit, verwijderen, of als prompt kopiëren en in Claude plakken. Werkt ook offline.
- **Slim zoeken** in gewoon Nederlands of Engels, met synoniemen en tolerant voor typefouten: "skill maken", "excel formule", "waarom werkt dit niet".
- **Veiligheidscheck** op elke skill; Prompt waarschuwt en vraagt eerst.
- **Openen als Claude start** (optioneel), licht en donker thema, zes accentkleuren, drie tekstgroottes.

## Installeren

Zie **[INSTALL.md](INSTALL.md)** (Nederlandse uitleg onderaan). Kort:

| Je computer | Download | Installeren |
|---|---|---|
| Windows 10 / 11 | `Prompt-…-windows.zip` | Uitpakken, dubbelklik op `Install Prompt.cmd` |
| macOS 12+ | `Prompt-…-macos.zip` | Uitpakken, rechtsklik op `Install Prompt.command` › Open |
| Linux | `Prompt-…-linux.tar.gz` | `tar xzf …`, `cd prompt`, `./install.sh` |

Je hebt **Python 3.9 of nieuwer met Tk** nodig; het installatieprogramma helpt je als het ontbreekt.

## Een skill delen

Klap in Prompt je skill open en klik op **Deel op marktplaats**. GitHub opent met je skill ingevuld; klik op *Commit changes* en *Create pull request*. Na een controle staat hij in ieders marktplaats. Zie [CONTRIBUTING.md](CONTRIBUTING.md).
